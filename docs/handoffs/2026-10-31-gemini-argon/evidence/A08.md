## 6. Assumptions and Risks Accepted

- **Reusable storage primitives for A09:** `S3ObjectStore`, `S3VectorsStore` (including `queryVectors` and `getVectors`), and key/pointer helpers (`ACTIVE_POINTER_KEY`, `manifestObjectKey`, `vectorsObjectKey`, `vectorRecordKey`) are exported from `services/chat/src/ingestion/index.ts` so **A09** can reuse the exact same SigV4 S3 and S3 Vectors transport and versioned key layout for hybrid retrieval.
- **Atomic pointer activation:** Because S3 object puts are atomic per key, `ingestKnowledgeIndex` writes `indexes/${indexVersion}/manifest.json` and `indexes/${indexVersion}/vectors.json`, writes all 14 vectors to S3 Vectors, and verifies all 14 vectors via `getVectors` before writing `indexes/active-pointer.json`. Any failure leaves `indexes/active-pointer.json` pointing to the previous verified index version.
- **Public access and voice:** `PUBLIC_CHAT_ENABLED=false` and `voice: false` remain untouched and enforced.
