A single chat turn that makes 1 internal MCP tool call consumes 2 requests (`1` message + `1` MCP) within the burst window, whereas a turn requesting 2 sequential MCP calls inside ~100 ms can hit API Gateway HTTP `429` unless `burstLimit` is raised (e.g., to `5`) in `infra/aws/lib/chat-stack.ts`. Even when throttled, the handler degrades gracefully using hybrid RAG context, and the probe's `portfolioRagMcp` prompt uses 1 MCP call (`get_case_study`) + hybrid RAG (`4` chunks) within the `burstLimit: 2` budget.
2. **Lambda Bundling of `services/portfolio-mcp/src/client.ts`:**
   - As documented in Section 1, `services/chat/build.cjs` (outside A23's owned paths) should include `nodePaths: [path.resolve(__dirname, 'node_modules')]` so `esbuild` resolves `@smithy/signature-v4`, `@smithy/core/protocols`, and `@aws-sdk/credential-provider-node` when bundling `services/portfolio-mcp/src/client.ts`.
